01 / Centro de operaciones

La nave, por dentro.

Cada módulo cumple una misión. Por ahora todos trabajan para investigar y aprender, nunca para enviar órdenes reales.

🔋CONSULTA PRIVADA

Batería y sistema

Estado de carga, memoria y almacenamiento. Los porcentajes seleccionados se muestran en el tablero público.

📡CADA 5 MIN

Mercado

Captura periódica de precios de Kraken y Pionex, almacenados localmente para análisis.

🌊CADA 5 MIN

Flujo y liquidez

Volúmenes, spreads, operaciones y profundidad. Buscamos contexto, no señales mágicas.

🧠EN DESARROLLO

Análisis

Datos históricos, tendencias, volatilidad y pruebas de ideas con costes realistas.

🛡️SOLO LECTURA

Puente seguro

GitHub transmite consultas con acciones permitidas. Sin terminal remota libre.

💌CADA HORA

Telegram

Reporte de batería, conectividad y monitoreo local, sin compartir claves financieras.

02 / Observatorio

Los mercados bajo la lupa.

El universo inicial incluye criptoactivos y futuros análisis de acciones tokenizadas. Las cotizaciones indicativas disponibles se muestran más arriba mediante fuentes públicas. Esta web no publica nuestras posiciones.
